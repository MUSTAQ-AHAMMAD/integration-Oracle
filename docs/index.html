Java Middleware — integration-Oracle

Oracle ADF · Java EE · Quartz Scheduler · JAX-WS SOAP · JPA/EJB · OkHttp REST

Oracle Fusion ERP Java SE 8+ JAX-WS SOAP Oracle ADF 12.x Quartz Scheduler JPA 2.1 / EJB 3.x

Overview

This documentation covers the Java EE middleware that synchronises data between Oracle Fusion ERP, VendHQ POS, and Opencart E-commerce. The platform runs on Oracle WebLogic Server 12.x and uses Oracle ADF for its web UI.

SharedResources Middleware

Package: innovate.tamergroup.shared.utils — core utilities shared by all integration modules.

BackgroundTaskExecutor

File: SharedResources/src/innovate/tamergroup/shared/utils/BackgroundTaskExecutor.java

A Singleton thread-pool manager backed by a 4-thread fixed-size ExecutorService. Integration tasks are submitted here to prevent long-running jobs from blocking the ADF UI thread.

BackgroundTaskExecutor executor = BackgroundTaskExecutor.getInstance();
executor.execute(
    () -> { /* integration logic */ },
    () -> schedulerBean.setStatus(Constants.IDLE)  // ExecutionListener callback
);

The second argument is an ExecutionListener whose onExecutionComplete() is called after the task finishes successfully.

IntegrationSchedulerBean

File: IntegrationJobs/…/jobs/IntegrationSchedulerBean.java

An Oracle ADF-managed bean that exposes the scheduler to the UI. Key operations:

  • startScheduler() — initialises and starts the Quartz Scheduler, registers all jobs.
  • stopScheduler() — gracefully shuts down the Quartz Scheduler.
  • manualTrigger() — bypasses the cron schedule and runs the main integration processor immediately via BackgroundTaskExecutor.
  • getStatus() — returns the current execution state (IDLE, RUNNING, AUTOMATIC, MANUAL, or NONE).

VendHQSalesToFusion Processor

File: IntegrationJobs/…/integrations/VendHQSalesToFusionInvRecIntParallel.java

The primary sales integration processor. For each unprocessed VendHQ sale:

  1. Fetches pending sales from the local backup table via SalesFusionPersistence.
  2. Groups sales by invoice key (date + customer type + credit flag).
  3. Maps each sale group to an InvoiceHeader + InvoiceLineModel list via FusionInvoiceMapping.
  4. Creates an AR invoice in Oracle Fusion via FusionInvoiceClient.saveInvoice().
  5. For each payment method in the sale, creates a Standard Receipt via FusionReceiptClient.saveStandardReceipt().
  6. Applies each receipt to the invoice via FusionReceiptClient.saveApplyReceipt().
  7. Creates bank-charge Misc Receipt via FusionReceiptClient.saveMiscReceipt().
  8. Creates an inventory transaction via FusionInvTxnService.
  9. Creates a GL journal entry (non-NORMAL customers only) via FusionJournalClient.
  10. Updates SalesIntegrationStatus to PROCESSED and sends an email summary via ExceptionAlerter.

FusionItemsToVendHQ Processor

File: IntegrationJobs/…/integrations/FusionItemsToVendHQItemsIntegration.java

Fetches the Oracle Fusion item catalogue via FusionItemsService, transforms each item to a VendHQ ProductCreate via FusionItemsToVendHQItemsTransformation, and upserts into VendHQ using InsertObjectVendHQ. Brand and category metadata are persisted locally via BrandVendHQPersistence and ItemVendHQPersistence.

FusionInventorySync Processor

File: IntegrationJobs/…/integrations/FusionInvToVendHQInvIntegration.java

Fetches on-hand quantities per outlet per item from Oracle Fusion via FusionAvailableQtyService, transforms them via FusionInvToVendHQInvTransformation, and updates VendHQ inventory levels using InsertObjectVendHQ. Outlet mappings are loaded via OutletVendHQPersistence.

FusionOnHandQtyFetch Processor

File: IntegrationJobs/…/integrations/FusionOnHandQtyFetch.java

Fetches on-hand quantities from FusionOnHandQtyService and persists them to the Oracle database via ItemOnHandSalesPersistence. Used for local reporting without requiring a live Fusion call at query time.

Full 8-Step Oracle Fusion API Sequence

Executed by VendHQSalesToFusionInvRecIntParallel for each sale group:

  1. GET /customers (REST) — resolve CustomerId / OrgId via customer account number
  2. GET /unitsOfMeasure (REST) — resolve Oracle UOM codes (cached per run)
  3. createSimpleInvoice (SOAP) — create AR invoice via FusionInvoiceClient
