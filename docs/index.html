integration-Oracle

Production-grade Enterprise Integration Platform — Oracle Fusion ERP ↔ VendHQ POS ↔ Opencart E-commerce

Oracle Fusion Node.js + TypeScript Python FastAPI Docker + Kubernetes Production Ready

Overview

This repository contains two integration platforms that synchronise data between Oracle Fusion ERP, VendHQ POS, and Opencart E-commerce:

🚀
Vyrooq
Modern cloud-native microservices platform. 10,000+ tx/hr. Docker + Kubernetes ready.
vyrooq/
🖥️
Oracle CRM
Node.js web application with RBAC, reporting, and Oracle Fusion integration UI.
oracle-crm/
☕
Legacy ADF Platform
Java EE / Oracle ADF monolith — archived for reference. Use Vyrooq for new installs.
Root dir
ℹ️
New installations should use the Vyrooq platform. The legacy ADF application is archived for reference only.

Quick Start

  1. Clone the repository: git clone https://github.com/MUSTAQ-AHAMMAD/integration-Oracle.git
  2. Change into the Vyrooq directory: cd integration-Oracle/vyrooq
  3. Copy and edit environment file: cp .env.example .env — set FUSION_BASE_URL, FUSION_USERNAME, FUSION_PASSWORD
  4. Start infrastructure services: docker compose up -d postgres redis rabbitmq kafka zookeeper
  5. Wait ~30 s for services to initialise, then start application: docker compose up -d gateway-api fusion-adapter reconciliation-engine
  6. Verify: curl http://localhost:3000/health
⚡
One-command automated setup: run ./quick-start.sh from the vyrooq/ directory.

Vyrooq — Modern Integration Platform

Vyrooq is a production-ready, cloud-native middleware platform built on a microservices architecture. It processes 10,000+ transactions per hour (40× faster than the legacy Java system) with horizontal auto-scaling from 2–50 workers.

Key Features

  • Event-driven messaging via Kafka + RabbitMQ
  • Distributed task queuing with BullMQ + Redis
  • Durable workflows via Temporal.io
  • Exponential backoff with 50 retry attempts
  • Transaction fingerprinting for idempotent processing
  • Full observability: OpenTelemetry · Grafana · Prometheus · Loki
  • Admin APIs for pause / resume / replay
  • Event sourcing for complete audit trail

Oracle CRM

A comprehensive Node.js web application (oracle-crm/) with role-based access control that manages Oracle Fusion Cloud integration, supporting both Odoo and VendHQ data sources with real-time monitoring, reporting, and user management.

Features

  • Hierarchical RBAC with 5 permission levels
  • Dashboard statistics, migration reports, job history, analytics
  • Odoo POS & VendHQ sales synchronisation
  • Automated retry for failed records
  • Multi-currency: AED, SAR, KWD, OMR, BHD, QAR
  • Multi-country, multi-store Oracle metadata mapping
  • Cron-based scheduling with incremental sync tracking
  • Duplicate prevention via fingerprinting
  • Multi-channel notifications

Oracle CRM — 16 Business Calculations

The Oracle CRM implements all 16 calculation functions originally written in Java, now ported to JavaScript (oracle-crm/src/calculations.js).

#CalculationFormula / Rule
1Timezone hoursMath.trunc(tzOffset)
2Timezone minutes((abs × 100) % 100) × 60 / 100
3Adjusted GL DateutcDate + hours + minutes
4Days since last sale(now − lastDate) / 86,400,000
5Day window capdaysToAdd <= 7 ? daysToAdd − 1 : 7
6Invoice grouping key{day}-{month}-{year}{customerType}[**Credit]
7Unit Selling PriceABS(totalPrice / quantity)
8Discount Item qtyForce to 1 if itemName="Discount Item" AND price > 0
9Conversion Rate TyperateIsCorporate=1 → "Corporate" else "User"
10Inventory qtyquantity × −1
11Transaction Typeprice=0 → Issue/RMA by qty sign; price>0 → Issue; price<0 → RMA
12Cash accountregion=KW → "Cash KW" else "Cash"
13Bank chargesamount × bankRate × (tax + 1) (capped at 10 for OM Debit Card)
14Journal chargeFixed freight OR saleTotal × bankChargeRate
15Period nameformat(date, "MMM-yy") e.g. "Jan-24"
16Message truncationmessage.substring(0, 500)

📦
The legacy Oracle ADF application is archived for reference only. All new installations should use the Vyrooq platform.

Legacy — SharedResources Middleware

Package: innovate.tamergroup.shared.utils

BackgroundTaskExecutor

A Singleton thread-pool manager (4-thread fixed pool) that runs integration tasks asynchronously to prevent long-running jobs from blocking the UI thread.

BackgroundTaskExecutor executor = BackgroundTaskExecutor.getInstance();
executor.execute(
    () -> { /* integration logic here */ },
    () -> System.out.println("Task completed!")
);

ExecutionListener

A callback interface with a single method onExecutionComplete() fired by BackgroundTaskExecutor when a background task finishes successfully.

ExecutionListener listener = () -> schedulerBean.setStatus(Constants.IDLE);
BackgroundTaskExecutor.getInstance().execute(integrationTask, listener);

Full 8-Step Oracle Fusion API Sequence

  1. GET /customers — resolve CustomerId / OrgId
  2. GET /units — resolve Oracle UOM codes (cached)
  3. POST /receivablesInvoices — create AR invoice
  4. POST /receivablesReceipts — create standard receipt per payment method
  5. POST applyReceiptOnAccount — link receipt to invoice
  6. POST /receivablesReceipts (misc) — create bank charge receipt
  7. POST /inventoryTransactions — create stock movement records
  8. POST /journals — create GL journal (non-NORMAL customers only)

Security

  • Oracle / VendHQ credentials stored only in .env files — never in source code
  • HTTP Basic Auth is sent only to Oracle Fusion APIs over HTTPS
  • .gitignore excludes .env and node_modules/
  • No credentials are logged or exposed in API responses
  • JWT tokens signed with JWT_SECRET — production throws on startup if unset
  • Role-based access control enforced on every API endpoint
  • Privilege-escalation protection — users cannot assign roles above their own level
🔒
Change all default passwords immediately after first deployment. Never use configureToIgnoreCertificate() in production environments.
